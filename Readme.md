# 🎬 VideoTube

A full-stack video sharing platform inspired by YouTube, built with the MERN stack. Users can upload videos, like/dislike, comment, subscribe to channels, create playlists, and track their watch history.

## ✨ Features

- 🔐 User authentication (Register, Login, Logout) with JWT & secure cookies
- 📹 Video upload, playback, and management (Cloudinary integration)
- 👍 Like / 👎 Dislike videos
- 💬 Add, view, and delete comments
- 📺 Subscribe / Unsubscribe to channels
- 📋 Create, edit, delete playlists and add/remove videos
- 🕘 Watch history tracking
- ❤️ Liked videos page
- 🔍 Search videos
- 👤 Channel profile pages with subscriber counts
- ✏️ Edit profile (avatar, cover image, account details)
- 📱 Fully responsive UI
